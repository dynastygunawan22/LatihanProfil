## 📋 Fitur & Ketentuan Tugas

### 1. Struktur HTML5 & CSS
- [x] Kerangka HTML5 lengkap dengan `<title>` berisi nama mahasiswa.
- [x] Struktur semantik lengkap (`<header>`, `<nav>`, `<main>`, `<footer>`).
- [x] Satu `<h1>` berisi nama dan `<h2>` pada setiap seksi halaman.
- [x] Paragraf deskripsi `<p>` serta daftar hobi dengan tag `<ul>` dan `<li>`.
- [x] Foto diri (`foto-profil.jpg`) dengan atribut `alt` deskriptif.
- [x] Tabel jadwal perkuliahan dengan baris header kolom `<th>`.
- [x] Tautan ke LinkedIn dan GitHub yang terbuka di tab baru (`target="_blank"`).
- [x] Form kontak berisi input Nama, Email, Pesan, dan tombol Kirim.
- [x] Tata letak dan pewarnaan modern menyerupai ilustrasi tugas.

### 2. Tambahan Baru: JavaScript & jQuery
- [x] **JavaScript / jQuery Toggle Tabel**: Tombol interaktif untuk menampilkan dan menyembunyikan tabel jadwal kuliah (`Sembunyikan jadwal` / `Tampilkan jadwal`).
- [x] **JavaScript Form Validation**: Validasi form pada event submit yang memunculkan pesan peringatan saat input Nama atau Email kosong.
- [x] **jQuery CDN & Penulisan Ulang dengan `$()`**: Memuat pustaka jQuery v3.7.1 dari CDN resmi Google/jQuery, lalu mengimplementasikan efek manipulasi DOM dan animasi toggle menggunakan sintaks jQuery `$()`.
